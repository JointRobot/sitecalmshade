# Calm Shade

Invite-only homestay collective ("where even crows, look like birds") — guests browse, chat, and book through one always-awake WhatsApp concierge; hosts keep 97% of every confirmed booking.

Single-file app: the entire product is `index.html` (no build step, no dependencies). Deploy = copy `index.html` to the web root. See `HANDOVER.md` for the full operational handover (deploy steps, codebase map, launch checklist).
